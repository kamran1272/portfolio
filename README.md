Personal portfolio website for Kamran Khan, a full-stack web developer focused on React, Laravel, and practical SEO improvements.

> **Live site:** https://kamran1272.github.io/portfolio/

## Overview

This portfolio highlights:

- React and Laravel project work with case-study details and live demos
- Service offerings for websites, dashboards, and SEO improvements
- Professional contact options and CV download
- Technical SEO basics such as metadata, structured data, sitemap, and robots rules
- Live GitHub activity pulled from the GitHub API

## Tech stack

- React 19 + Vite
- Tailwind CSS 4 + DaisyUI
- React Router 7
- EmailJS — working contact form
- Swiper, React Icons, Font Awesome — UI details

## Project structure

- `src/components`: reusable UI grouped by feature and responsibility
- `src/data`: site, project, capability, technology, and GitHub configuration
- `src/layouts` and `src/routes`: application shell and route configuration
- `src/assets`: imported images and icons
- `public`: static SEO files, CV, and public assets

## Development

```bash
npm install
npm run dev
```

## Production build & preview

```bash
npm run build
npm run preview
```

The site deploys to GitHub Pages (`gh-pages` branch) at https://kamran1272.github.io/portfolio/
